# 数据准备

本仓库不重复分发 DocRED 和 Re-DocRED 原始数据。

## DocRED

- 官方仓库：https://github.com/thunlp/DocRED
- 数据目录：https://github.com/thunlp/DocRED/tree/master/data

本地运行时需准备 `train_annotated.json`、`dev.json`、`test.json` 及相应关系元数据文件。

## Re-DocRED

- 官方仓库：https://github.com/tonytan48/Re-DocRED
- 数据目录：https://github.com/tonytan48/Re-DocRED/tree/main/data

本地运行时需准备 `train_revised.json`、`dev_revised.json`、`test_revised.json` 及相应关系元数据文件。

论文图5、图6对应的分组评估结果分别见 `Experimental_Results/Grouped_Analysis/Related_Entity_Pairs.csv` 和 `Experimental_Results/Grouped_Analysis/Entity_Count.csv`。
